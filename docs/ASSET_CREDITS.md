# Asset provenance

All runtime game artwork is original procedural geometry created for this project: the block-built adventurer with modular body styles, six hairstyles, three tops, three pants styles, three shoe styles, and an original wardrobe preview platform, notched lily pads and veins, trees, cliffs, rocks, reeds, flowers, clouds, water shader, flag, splash droplets, landing cue, confetti, green combat frogs, red decoy frogs, yellow chance frogs, poison particles, collapsing pads, wooden baseball bat, and combat puff. No reference images are used as runtime backgrounds or textures.

The app icon and gold-and-purple Secret Perch badge are original SVG geometry. Jump, splash, victory, bat swing, bonk, and poison-defeat sounds are original synthesized WAV files generated by `scripts/generate_audio.py` using only the Python standard library. The background tracks “Platformer Rush” (level 1, by pulsia) and “Bouncing Beat pt2” (level 2), and “Lily Pad Rush” (level 3) were supplied by the user; their ownership and licenses have not been independently verified. There are no remote runtime assets, third-party art packs, or copied system fonts.

Godot 4.6 stable and its exported Web runtime are third-party software under the MIT license. The engine includes libraries and built-in fonts with additional notices. `GODOT_LICENSE.txt` and `GODOT_COPYRIGHT.txt` are copied from the official `4.6-stable` source tag and included beside the Web build. The UI uses Godot's built-in font.

The supplied concept image and three note images are retained unchanged under `reference/lily_pad_agent_starter/` as user-provided design references. Their ownership and reuse rights were not independently verified; they are not part of the playable Web build.

Official engine source: https://github.com/godotengine/godot/tree/4.6-stable


Version 0.8 adds original procedural fireflies (body, wings, glow and pickup particles), pink flowers on exploration pads, frog landing rings and crouch/hop/recovery motion, and an original synthesized firefly chime in `game/assets/audio/firefly.wav`. The generation source is `scripts/generate_audio.py`. Those additions did not introduce external artwork or audio.

## River Rapids additions

The curved terrain, roots, leaf veins, route markers, and wave fronts are procedural geometry authored for this project. `launch.wav`, `landing.wav`, and `rapids_wind.wav` are newly synthesized tones/noise, with no third-party samples. River Rapids reuses the existing Platformer Rush music track and its existing credit.


Version 0.10 adds an original procedural hoverboard (deck, gold tips, light rails, thrusters), rider stance, magnetic loop and spiral track, coral obstacles, lane arrows, and a checkered finish arch. No external models, textures, or additional audio were introduced.


Version 0.11 adds original procedural introductory-course geometry and protective rails. River Glide reuses the existing hoverboard, obstacles, synthesized effects, and Platformer Rush music credit.
